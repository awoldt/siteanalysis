```
https://siteanalysis.dev/api?site={SITE_URL}
```

This is a really easy-to-use API for scraping HTML data from public websites. Submit a valid URL and get HTML breakdown along with HTTP header information in seconds returned in JSON format. You can fetch this URL in your browser no need for API keys or account creation.

One of the entire points of this little project was to go back to fundamentals and *NOT* use AI to create it (although I will admit I used it to create the ui, but all backend Go code is handwritten. All bugs squashed took time and I had to use my brain to figure out the fixes). This was so much fun and brought back some passion for coding honestly.
